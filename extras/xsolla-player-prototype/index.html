How a build gets here

Every game on this page went through the Game Jam quest: twelve steps from a zip archive to a Draft build that testers can install.

Open the Game Jam quest
  1. 01

    Register

    Sign up in Publisher Account and create your first project.

  2. 02

    Prepare

    Add your game, download Build Loader, and copy the game's API key.

  3. 03

    Upload

    Run the upload app and drag in your build. It checks the files and sends them to Draft.

  4. 04

    Verify

    Paste the receipt, find the build row, and set the start file.
